# dailywordladderapp

A lightweight daily Word Ladder game built as a static web app.

What is included
- A daily challenge using a seeded word ladder
- A simple game loop where you add one-letter-at-a-time steps
- Validation for each move using a word bank
- Reset and reveal-solution buttons
- No dependencies required

How to run it
1. Open `index.html` directly in a browser, or
2. Serve the folder locally:

   python -m http.server 8000

3. Visit http://localhost:8000 in your browser

Project files
- `index.html` – page structure
- `style.css` – styling
- `app.js` – puzzle logic and daily challenge

This repo currently contains a working front-end game, ready to open locally.
